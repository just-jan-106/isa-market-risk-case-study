# Data handling policy

- `raw_private/` and `processed_private/`: excluded from Git by `.gitignore`; do not commit any real ISA exports.
- `public_sample/`: only publish licensed files or genuinely synthetic/anonymised safe examples.
- Do not use GitHub to store account statements, identifiable transactions, access keys or full sensitive exports.
- Before publishing a Tableau extract or BigQuery public table, inspect embedded data and sharing permissions.
